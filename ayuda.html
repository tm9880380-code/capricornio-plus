Centro de ayuda

Respuestas claras para continuar aprendiendo y resolver problemas habituales.

No puedo iniciar sesión

Comprueba que el correo esté escrito correctamente. Si olvidaste la contraseña, esta versión aún no dispone de recuperación automática: no crees varias cuentas con el mismo correo. Contacta al equipo del proyecto para recibir ayuda.

No carga una lección o un recurso

Verifica tu conexión y vuelve a cargar la página. Los recursos externos dependen de sus respectivos sitios. Si un enlace está roto, anota el título y la lección desde la que lo abriste.

Python no se ejecuta

La práctica de Python requiere conexión para descargar el motor en el navegador la primera vez. Si el programa tarda demasiado, se detiene automáticamente. Revisa la salida y vuelve a intentarlo con un ejercicio más pequeño.

Mi avance no aparece

Comprueba que estés usando la misma cuenta. El progreso de esta versión se guarda en la base de datos de la instalación. En alojamientos gratuitos sin almacenamiento persistente podría perderse al reiniciar.

¿Cómo reportar un problema?

Incluye la página, el paso que estabas realizando, el mensaje de error y el navegador. Nunca envíes contraseñas, códigos de acceso ni datos personales de terceros.
