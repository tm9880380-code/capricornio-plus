# Capricornio Plus

Plataforma educativa adaptativa con FastAPI, SQLite, diagnóstico inicial, seguimiento de competencias y progreso de lecciones.

Consulta [backend/README.md](backend/README.md) para instalación y ejecución.

La aplicación usa SQLite local. El primer acceso se realiza en `/` (inicio de sesión); crea una cuenta desde el enlace de registro.

**Importante:** el modelo de estimación BKT/IRT incluido es experimental y no equivale a una evaluación psicométrica validada.
