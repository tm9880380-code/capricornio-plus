# Accesibilidad

Capricornio busca ser utilizable con distintos dispositivos y formas de interacción. La versión actual es un punto de partida, no una declaración de conformidad WCAG.

## Criterios para revisión

- Navegación completa con teclado y foco visible.
- Etiquetas asociadas a cada campo y mensajes de error comprensibles.
- Jerarquía de encabezados y HTML semántico.
- Texto alternativo significativo para imágenes informativas.
- Contraste de texto y controles medido, no estimado visualmente.
- Zoom al 200 % sin pérdida de contenido ni funciones.
- Diseño responsive y áreas táctiles suficientes.
- Mensajes dinámicos anunciados con regiones aria-live cuando corresponda.
- No depender únicamente del color para comunicar aciertos o errores.
- Pruebas con lectores de pantalla y usuarios con discapacidad.

## Objetivo recomendado

Adoptar WCAG 2.2 nivel AA como objetivo de diseño y someter cada versión institucional a evaluación automatizada y manual. Una herramienta automática por sí sola no certifica accesibilidad.
