# Contribuir a Capricornio Plus

Gracias por ayudar a mejorar una plataforma educativa abierta.

## Principios

- Mantener la identidad visual y la paleta existentes.
- Priorizar recursos gratuitos, accesibles y de calidad.
- Enlazar a fuentes originales; no copiar cursos ni materiales protegidos.
- No incluir enlaces de afiliados, publicidad ni contenido que exija pago como requisito de una ruta gratuita.
- Separar hechos, recomendaciones y opiniones.
- No presentar diagnósticos breves como certificaciones.

## Añadir una lección

Cada lección debe incluir identificador único, título, concepto, explicación clara, ejemplo, actividad, pregunta de comprobación, opciones, respuesta y retroalimentación. Para ejercicios ejecutables, indicar lenguaje, resultado esperado y límites de ejecución.

## Añadir recursos

Cada recurso debe tener título, tipo, descripción, URL original, tema, nivel, fuente e idioma. Verifica que la página exista y que el contenido sea gratuito en el momento de incorporarlo. Respeta licencias y atribuciones.

## Calidad

- Ejecuta `pytest -q` y `python -m compileall -q backend`.
- Añade pruebas para cambios en API y persistencia.
- No incluyas credenciales, datos personales reales ni secretos.
- Documenta cambios de esquema, dependencias y despliegue.
